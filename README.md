# Crypto

UWP-приложение для просмотра рынка криптовалют, поиска активов, просмотра суточной динамики и конвертации в фиатные валюты. Данные предоставляет CoinGecko.

## Возможности

- рейтинг крупнейших активов с ценой, объёмом и капитализацией;
- поиск по названию и тикеру среди 250 валют;
- график цены выбранного актива за 24 часа;
- конвертация криптовалют в USD, EUR, GBP и UAH;
- обработка сетевых ошибок, тайм-аутов и некорректных ответов API.

## Запуск

1. Откройте `TestAssignment.sln` в Visual Studio с компонентом **Universal Windows Platform development**.
2. Восстановите NuGet-пакеты.
3. Выберите платформу `x64` и запустите проект `TestAssignment`.

Минимальная версия Windows — 10.0.17763.0, целевая — 10.0.19041.0.
